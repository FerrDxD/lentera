# Security Policy

We take the security of **LENTERA Score** seriously. If you discover a vulnerability, please follow these steps:

1. **Do not disclose** the issue publicly.
2. Email the security details to **security@lentera.test** (or the repository's security contact).
3. Include a clear description of the vulnerability, steps to reproduce, and the potential impact.
4. We will acknowledge receipt within 48 hours and work with you to resolve the issue.
5. Once fixed, we will publish a CVE‑style advisory and credit the reporter where appropriate.

The repository is covered by the MIT license, which grants you broad rights to use, modify, and distribute the software.
